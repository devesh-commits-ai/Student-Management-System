# 🎓 Student Management System

A modern **Student Management System** built using **Python, CustomTkinter, Tkinter and CSV**.

This application allows users to manage student records through a modern graphical user interface.



---

## ✨ Features

- ➕ Add Student
- 📄 View Students
- 🔍 Search Student
- 🗑 Delete Student
- 💾 CSV File Storage
- 📋 Treeview Table
- 🌙 Modern Dark GUI
- ✅ Input Validation
- ✅ Success & Error Message Boxes

---

## 🛠 Built With

- Python 3
- CustomTkinter
- Tkinter
- CSV Module
- ttk.Treeview
